# 📊 Análise de Vendas com Python e SQL

Projeto desenvolvido para praticar a integração entre **Python e MySQL**, utilizando **Pandas** para análise de dados e **Matplotlib** para visualização.

## 🚀 Tecnologias utilizadas

- Python
- Pandas
- Matplotlib
- SQL

## 📌 Sobre o projeto

O projeto utiliza um banco de dados MySQL contendo informações sobre vendas.

O Python se conecta ao banco de dados, consulta os dados da tabela **Vendas** e utiliza Pandas para calcular o valor total das vendas por categoria.

Por fim, o resultado é apresentado em um gráfico de barras utilizando Matplotlib.
